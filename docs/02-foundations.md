# 机器人基础：坐标、运动学、动力学与控制

## 先统一数据约定

| 量 | 工程内部标准 | 常见接口差异 |
|---|---|---|
| 位置 | m | 厂商 SDK 常用 mm，不能直接传入仿真 |
| 关节角/角速度 | rad / rad·s⁻¹ | Fairino 非实时状态字段为 degree |
| 力/力矩 | N / N·m | 电流不能不经标定当作力矩 |
| 四元数 | Isaac 资产状态常用 wxyz | ROS 消息字段为 xyzw；相机约定还涉及坐标轴 |
| 时间 | 单调时钟用于延迟，本地 wall clock 用于记录 | 跨机器单调时钟不能直接相减 |
| 图像深度 | 物理计算用 m | 当前采集 PNG 是 uint16 毫米，0 无效 |

转换必须同时验证单位、顺序、参考系与时间，不能只检查数组长度。

## 齐次变换与相机

记 `T_A_B` 为把 B 系坐标变换到 A 系：`p_A = T_A_B p_B`。

```text
T_base_object = T_base_camera × T_camera_object
T_base_camera = T_base_ee × T_ee_camera       # 眼在手上
```

矩阵相乘不满足交换律。ROS TF 的 parent/child、URDF joint origin 和模型 mesh origin 是不同概念；mesh 显示正确不代表工具坐标正确。

针孔反投影：`X=(u-cx)Z/fx, Y=(v-cy)Z/fy`。这里 Z 通常是沿光轴深度，不一定是到相机中心的欧氏距离。采集器使用的深度类型、camera intrinsics 与图像分辨率必须配套。裁剪/缩放图像后须更新内参。

## 正逆运动学

机械臂正运动学把关节 `q` 映射到末端位姿；逆运动学求满足目标位姿的 `q`。IK 可能多解或无解，必须检查关节限位、奇异点、碰撞和连续性。MoveIt 的规划场景、SRDF group、工具链接和 TF 必须与实际 URDF 一致。

雅可比满足 `v = J(q) q_dot`，描述关节速度到末端速度的局部关系；力的映射为 `tau = J^T F`。在奇异点附近用阻尼最小二乘等方法，不把大关节跳变当成正常 IK 输出。

## 运动学动画与动力学

运动学更新直接设置 `q`、物体/根位姿。它适合轨迹可视化、感知数据管线与状态镜像，但运动不必由受力产生。

动力学近似满足：

```text
M(q) q_ddot + C(q,q_dot) q_dot + g(q) = tau + J_contact^T lambda
```

仿真还需求解关节约束、接触和摩擦。接触不穿透、摩擦锥、质量/惯量和控制饱和共同决定结果。修改根位置或反复写状态可以掩盖滑移和跌倒，不能据此验证策略。

本工程的 FR5 抓取数据属于运动学附着；D1 PhysX 驱动/PPO 步进属于关节目标驱动的动力学。可视化副本若逐帧复制物理刚体姿态，只是渲染显示；它不能向物理模型提供额外运动。

## PD 与多频率控制

位置 PD 的简化表达：`tau = Kp(q_target-q) + Kd(qdot_target-qdot)`。Isaac 隐式驱动由物理求解器处理，不等同于在 Python 里显式套这个公式，但增益与限幅仍影响稳定性。

轮足控制常设 `Kp=0`、用速度误差阻尼产生力矩。轮角连续增长，不应保留 ±π 位置限制。D1 的仿真轮速动作范围是 ±6 rad/s，速度上限 25 rad/s 和力矩上限 50 Nm 是另一层约束。

物理步长与策略步长：`dt_control = decimation × dt_physics`。当前 D1 为 `0.005×4=0.02 s`。改变频率同时影响增益、观测噪声、积分奖励、action-rate 惩罚与策略响应；不能只改 FPS。

## 强化学习与模仿学习

RL 从 `(s,a,r,s',done)` 学最大化折扣回报的策略；PPO 限制单次策略更新幅度。奖励上升只说明在当前环境指标上优化，可能出现空转、原地站立等投机。

模仿学习从演示学 `a~pi(o)`；行为克隆是监督学习。若标签是关节位置目标，不能将它误解释为末端位移或力矩。训练和部署观测分布不同会产生累积误差，需要闭环评估，而不只看离线 loss。

推荐基础练习：实现角度/四元数转换单测、手算两段坐标变换、画一个关节阶跃响应、说明一次 episode 为什么 reset；完成后再读 [模型](03-robot-assets.md) 与 [训练](09-d1-max-rl.md)。
