## 可复查的历史 D1 数值

本机历史报告来自 2026-10-24 的服务器运行，关联路径在 [D1 章节](09-d1-max-rl.md)。[机器可读摘录与源码副本 hash](../evidence/historical-training.json)保留证据定位。主要记录：

- 256 环境固定轮速检查：平均位移 0.9473686 m、drive reset 0、平均四轮接触力模长和 415.9926 N。
- 64×10 PPO：15,360 transition；256×10 续训：61,440 新 transition。
- 64 环境固定 0.3 m/s 评估：首次短测 MAE 0.2369863 m/s，续训短测 MAE 0.3268832 m/s；导出推理最大动作差均为 0。

这些值证明训练流程曾经跑通，也直接说明现有策略不能称为收敛。要用于论文/对外报告，应重新锁定代码/资产并复验，而非只引用本手册。

## 下一步技术缺口

| 缺口 | 为什么重要 | 下一步验收 |
|---|---|---|
| ROS install 缺失/profile 错误 | 旧启动步骤不可直接使用 | 审阅后离线重建工作区，验证 source 与依赖，不启动 hardware |
| 相机没有 publisher | 无有效实时观测 | 单独确认驱动/设备占用/时间/内参/对齐 |
| 质量惯量/碰撞/电机未实测 | 动力学与真实机器人有差异 | 参数辨识与仿真对照，记录误差 |
| FR5 使用附着抓取 | success 不代表接触抓取 | 物理夹爪/接触/保持成功定义 |
| D1 策略未收敛 | 无稳定速度跟踪效果 | 多 seed 训练与多指令长期评估 |
| 视觉/语言任务未接通 | 只有源码不足以形成应用 | 独立环境复现一个闭环任务 |
| 数据不等于 RLDS/VLA schema | 动作维度/夹爪/时序不同 | 数据卡、转换单测、离线回放 |
| 实机状态与策略链路未验收 | 协议/状态估计/延迟未知 | 离线＋单向只读反馈，另行定义实机试验 |

列明缺口属于完成文档的一部分，不是承诺本次替用户修完所有技术工程。本任务交付是全面、可核查的技术文档与学习路线，独立审核门槛见 [审核记录](review.md)。
